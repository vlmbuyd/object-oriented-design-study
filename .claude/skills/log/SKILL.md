# /log — 하루 학습 기록

`logs/sessions/{YYYY-MM-DD}.md` 에 append 한다.

## 가장 중요한 원칙
이 기록의 주인은 **사용자**다. 네 설명을 요약해 채우지 않는다. 사용자가 자기
언어로 도달한 문장이 기록의 중심이다.

## 항목 구조 (세 줄)
```
Q. (사용자가 던진 질문. 사용자가 쓴 그대로. 다듬거나 줄이지 않는다)
A. (사용자 말로 정리한 답)
근거. (책 p.87 / dojo/07/after.tsx 같은 확인 지점만)
```

### "A." 채우는 법 (핵심)
- 대화 중 사용자가 **이미 자기 언어로 답한 게 있으면 그 문장을 그대로** 가져온다.
- 없으면 **지어내지 말고 되묻는다**: "이거 네 말로 하면 뭐야?" 답하면 그대로 적는다.
- 사용자가 답을 못 하면 **A. 를 비우고 미해결 목록으로 내린다.** 빈칸이 네 문장으로
  채워지는 것보다 훨씬 낫다. 그게 내일 할 일이다.

### AI 문장 제한
- 네가 쓴 문장은 앞에 `[보충]` 을 붙이고 **한 세션에 최대 3개.**
- `[보충]` 은 사용자가 놓친 사실을 짧게 못 박을 때만. **두 줄 이내.**
- 네 설명을 요약해 `A.` 자리에 넣는 것은 **금지.** 그건 학습 기록이 아니라 네
  출력물 아카이브가 된다.

## 마지막 질문 (딱 하나)
기록을 다 쓴 뒤 묻는다: **"오늘 배운 걸 한 문장으로 하면?"**
사용자 답을 그날 파일 맨 위 `> 💡` 콜아웃에 **그대로** 박는다. 다듬지 않는다.
(이 한 줄은 해당 장 `notes/{NN}-*.md` 의 `> 💡` 에도 그대로 반영할 수 있다)

## 파일 모양
```
# {YYYY-MM-DD} / {장}
> 💡 (사용자 답 그대로)

## 질답
Q. / A. / 근거.

## 미해결
- [ ] (답 못 한 질문 그대로)

## 오늘 만든 것
- notes/007-....md
```

## 기록 + 미해결 이월
- `python3 scripts/log_event.py --type log --chapter {NN} --note logs/sessions/{날짜}.md`
- 미해결 항목을 `state/progress.json` 의 `open_questions` 에 넣는다. 다음 `/pre` 가
  여기서 먼저 꺼낸다.
- `logs/sessions/*.md` 는 사람이 읽는 용도다. **통째로 읽지 않는다.**
