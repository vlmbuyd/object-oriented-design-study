# /pre {장} — 읽기 전 예열

원문을 **열지 않는다.** 목표는 예측을 만들어 읽을 때 걸리게 하는 것.

## 절차
1. `state/progress.json` 을 읽어 이 장 관련 **지난 세션 미해결 항목**(open_questions)이
   있으면 **가장 먼저** 꺼낸다. "지난번에 이거 못 풀고 넘어갔지?" 하고 다시 던진다.
2. 제목만 확인한다. INDEX 를 Read 하지 말고 grep:
   `grep -E "^\| 0?{장} " book/INDEX.md` → 제목 한 줄만.
   (INDEX 가 아직 없으면 제목 없이 진행)
3. 예측 질문을 **정확히 3개** 던진다. 아래 뼈대에서 장에 맞게 변형:
   - "이 장은 무슨 **문제**를 풀 것 같아?"
   - "지금 네 React 코드에서 여기랑 걸리는 데가 있어?"
   - "제목의 이 단어, 지금 네 정의로는 뭐야?"
4. **답을 절대 주지 않는다.** 맞다/틀리다도 말하지 않는다. 예측은 틀려도 된다.
5. 사용자의 답을 `scratch/{NN}.md` 상단에 `## 예측 (/pre)` 블록으로 저장한다.
   (NN = 두 자리 장번호. 파일 없으면 만든다)

## 기록
- `python3 scripts/log_event.py --type pre --chapter {NN}`

## 하지 말 것
- 이 장의 내용을 미리 요약/설명하기. 예측의 의미가 사라진다.
- 3개보다 많은 질문. 예열은 3분이다.
