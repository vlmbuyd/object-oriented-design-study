# /recap {장} — 되짚기 + 노트 만들기

오늘 읽은 장을 되짚는다. `scratch/{NN}.md` 를 읽고 원문과 대조한다.

## 절차
1. `scratch/{NN}.md` 를 읽는다(이건 사용자 원본이라 읽어도 된다).
2. 원문 대조가 필요하면 **book-reader 서브에이전트에 위임**한다. 직접 청크를 열지
   않는다. FF 근거가 필요하면 출처 `toss-ff` 로 함께 요청한다.
3. 사용자의 끄적임을 **네 가지로 분류**해 대화로 돌려준다.
   - **내가 스스로 도달한 것** — 칭찬은 짧게. 이게 노트의 주인공이다.
   - **어긋난 것** — 어디가 왜 다른지 + 페이지(p.xx).
   - **빠진 것** — 핵심인데 못 짚은 것, **최대 2개만**. 더 나열하면 요약이 된다.
   - **좋은 질문 하나** — 답 대신 힌트로 돌려준다(원칙 1).

## 노트 작성: `notes/{NN}-{제목}.md`
노션에 옮길 거라 **일반 마크다운**으로 쓴다. frontmatter·위키링크 금지.
원문 문장 그대로 옮기지 말고 사용자 문장 + (p.xx).

```
# {NN}. {제목}
> 💡 한 줄 요약 (사용자가 /log 에서 쓴 "한 줄"이 있으면 그걸, 없으면 비워둠)

## 내가 먼저 도달한 것
(이 섹션이 노트의 주인공. 사용자 문장을 최대한 살려서)

## 책이 더 밀어준 것
(어긋난 것 + 빠진 것, 페이지 참조)

## 남은 질문
- [ ] ...

## 연결
(관련 개념, 다른 장 번호를 텍스트로 언급)
```

## 복습 카드 등록 (핵심 개념 2~3개)
```
python3 scripts/review.py add --chapter {NN} --front "질문" --back "답" --tags 태그
```
카드 앞면은 질문형으로. 답을 그대로 외우게 하지 말고 원리를 떠올리게.

## 기록
- `python3 scripts/log_event.py --type recap --chapter {NN} --note notes/{NN}-{제목}.md`
- `state/progress.json` 의 chapters[{NN}] 상태를 갱신한다.
