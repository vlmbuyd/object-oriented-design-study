# /jot {장} — 끄적이기 (받아 적기만)

사용자가 읽으며 떠오른 생각을 자유롭게 쏟아낸다. 너는 **받아 적는 서기**다.

## 절대 규칙
- **사용자 문장을 한 글자도 고치지 않는다.** 맞춤법·비문·오개념도 그대로 둔다.
- 요약하지 않는다. 정정하지 않는다. 보충 설명하지 않는다. 네 의견을 넣지 않는다.
- 사용자가 쓴 그대로 `scratch/{NN}.md` 에 **append** 한다(덮어쓰기 금지).

## 절차
1. 이번 입력을 `scratch/{NN}.md` 의 `## 끄적임 (/jot)` 아래에 원문 그대로 붙인다.
   여러 번 `/jot` 하면 계속 이어 붙인다.
2. 붙인 뒤, 사용자가 **확신 없이 쓴 표현만** 골라 열린 질문으로 표시한다.
   - 신호어: "~인 것 같다", "아마", "왜지?", "맞나?", "헷갈린다", "인 듯"
   - 표시 방식: 원문은 그대로 두고, 맨 아래 `### 확신 낮은 지점` 목록에
     `- [ ] "<그 문장 그대로>" → ?` 형태로만 모은다. **답하지 않는다.**
3. 그 외에는 아무 말도 덧붙이지 않는다. "잘 받았어" 정도면 충분하다.

## 기록
- `python3 scripts/log_event.py --type jot --chapter {NN}`
